# OmniWM Keyboard Shortcuts

> Source of truth: `home/darwin/omniwm-settings.toml` — regenerate this table from
> the file, not by hand.

**Hyper** = hold `Caps Lock` (remapped by Karabiner to `Ctrl+Opt+Cmd`), or hold
**Left Option** for the built-in OmniWM hyper trigger (150&nbsp;ms threshold).

## Layout & Columns

| Shortcut | Action |
|----------|--------|
